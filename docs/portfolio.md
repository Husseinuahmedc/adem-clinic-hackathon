# ADEM — Portfolio case study

**Category:** Full-stack web prototype / hackathon  
**Result:** 4th place  
**Role:** Sole software developer, with OpenAI Codex as a development assistant  
**Collaborator:** UI/UX design and brand identity by teammate  
**Stack:** Next.js, TypeScript, plain CSS, PostgreSQL schema and partial integration

## Short English summary (for sitehie.info)

**ADEM is an Arabic-first clinic booking and reception management prototype created during a hackathon, where our team placed 4th.** I developed the application, including the patient booking flow, receptionist dashboard, booking-state logic, filters, WhatsApp message preparation and backend/database foundation, with OpenAI Codex as a coding assistant. A teammate created the UI/UX design and visual identity.

The project uses Next.js and TypeScript. PostgreSQL tables and server actions were prepared, while the dashboard still uses browser localStorage in the demo version. The next engineering step is to centralize both sides on one database and implement staff access controls.
